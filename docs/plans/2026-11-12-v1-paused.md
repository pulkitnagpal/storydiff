## Build approach I had settled on (reuse unless the new design changes it)

- One npm package at the repo root. Source is TypeScript in `src/`. Node 22+ runs tests straight from `.ts` with `node --test`. `tsc --noEmit` does the type check. esbuild bundles the CLI, the Action and the single-file viewer into `dist/`. rough.js (MIT) is a dev dependency bundled into the output, so installing the package pulls in no runtime dependencies.
- **One board renderer** (`src/board/`) shared by the viewer and `storydiff render`. It is a pure function that turns the parsed doc, the layout and the view state into an SVG string. It uses `rough.generator().toPaths()`, which needs no DOM. Colours are `var(--token)` in style attributes, so the viewer switches theme without a redraw. The standalone SVG embeds the same tokens with a dark-mode media query.
- **Checker:**
  - The base defaults to the merge-base with `origin/HEAD`, then `main`, then `master`.
  - The diff is base against the working tree, because the agent has not committed yet.
  - Base tests run in a `git archive` copy with `node_modules` symlinked in.
  - Test names come from TAP output. The default is `node --test --test-reporter=tap`, overridable with `--test-cmd`.
  - The session log is the newest `.jsonl` in `~/.claude/projects/<repo path with non-alphanumerics as ->/`, overridable with `--session`.
  - Any `say` line over 25 words gets a warning.
- **Publish:** the spec goes into the PR body as a fenced `storydiff` block, plus `<!-- storydiff-check {...} -->` holding the commit, a spec hash and the said-check results. In CI, a quote missing from that record counts as failing.
- **Viewer link:** `#s=<base64url(deflate-raw(spec))>&r=<report>`, also `#pr=owner/repo/N` for public repos. The default host is `https://pulkitnagpal.github.io/storydiff/` (the personal account's login), set in one constant.
- **Action:** a `node24` JS action. It reads the PR body over REST with `GITHUB_TOKEN`, re-runs the file and test checks, upserts one comment with a marker, and sets a `storydiff` commit status. The GitHub client is injectable so tests can fake it.
- **Plugin:** `plugin/.claude-plugin/plugin.json`, `skills/storydiff/SKILL.md` built from the guide, and `commands/storydiff.md`. Also a marketplace file at the repo root.
- **Tools on this machine:** Node 25.9, npm 11, Claude Code CLI 2.1.322, rough.js 4.6.6, esbuild 0.28, TypeScript 7.0. Google Chrome is not installed, so the README screenshot will need the built-in browser or another route.
